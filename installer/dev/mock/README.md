# Макеты установщика

`index.html?page=<id>` — страницы мастера и окна Windows в размере клиента Inno 6.7
`WizardStyle=modern` при 100 % (600×432). Только для согласования вида и текстов, в сборку не входят.
Открывать через Playwright: шрифты `/fonts/*` и картинки `/gen/*` (из `installer/gen`) отдаёт
`page.route`. Снимки — `installer/dev/screenshots/mock/<id>@{1,1.5,2}x.png` (не в гите).

## Сценарий → страницы

| сценарий | страницы |
|---|---|
| ARM64 / Windows старее 1809 | стандартное окно Inno с новым текстом (`arm64`, `oldwin`) |
| новая установка | `welcome` → `dir` → `tasks` (кнопка «Установить», страницы «Готово к установке» нет) → `installing` (если нет WebView2 — `installing-webview2`, при сбое окно `webview2-failed`) → `finished` |
| обновление | `maint-update` («Обновить») → `installing` → `finished-update` — 2 клика |
| переустановка / откат | `maint-reinstall` / `maint-rollback` (пункт с ⚠ не выбран, «Далее» неактивна до выбора) |
| переезд с DualVPN | `maint-legacy` (плашка); если перенос не удался — `legacy-failed` |
| старая служба помечена на удаление | `pending-delete`: «Перезагрузить сейчас / Позже» |
| служба не запустилась | `service-failed`; если «Повторить запуск» помог — `finished` |
| туннель не поднялся после обновления | `finished-update-warn` |
| удаление | `uninstall-confirm` → `uninstall-configs` → `uninstall-progress` → `uninstall-done` |

В `uninstall-configs` кнопки «Отмена» нет: вопрос задаётся уже после подтверждения удаления
(`CurUninstallStepChanged`, `usUninstall`), и прервать удаление оттуда нельзя.

| меню обслуживания | три голых пункта | строка «Установлено: 0.3.5 · В этом файле: 0.3.7», пункты с пояснениями, ссылка «Изменить параметры» |
| сбой службы | окно с «ОК» и «Перезагрузи…» | отдельная страница с ✕, причиной и кнопками «Повторить запуск», «Открыть журнал», «Скопировать путь», «Сообщить о проблеме» |

| WebView2 | окно «Поставь его сам: …» | окно «Повторить / Продолжить без него» |

На Windows для ARM он пока не работает: драйвер сетевого адаптера нельзя запустить через эмуляцию — туннель не поднимется. (Сообщение Inno одно на любую неподходящую архитектуру.) |
| подтверждение удаления | Вы действительно хотите удалить… | Удалить TunnelVPN? VPN отключится, служба и автозапуск будут удалены. |
