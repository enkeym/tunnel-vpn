# Карта скрытых связей — индекс

Связи, которые компилятор и тесты не ловят: «тронул X → обнови Y, потому что Z».
Файл домена подключает хук по его `paths:`, когда правка попала в эти пути;
перед коммитом (impact-проход) открывай его по индексу. Формат строки:
`- <домен> — <файл>.md — <одна фраза>`, проверка ссылок и глобов:
`node ~/.ai-hooks/bin/check-impact-map.mjs`.

- служба и канал: команды — `service-ipc/commands.md` — имена и права команд канала, туннель в payload, `apply` и `add-config`
- служба и канал: запуск — `service-ipc/run.md` — `test-config`, `set-enabled`, флаги и запуск туннелей через канал
- служба и канал: статус — `service-ipc/status.md` — ключи статуса для трея, окна и CLI
- служба и канал: журнал — `service-ipc/singbox-log.md` — журнал sing-box для сторожа: перезапуск, запасной конфиг, возврат выхода
- окно: мост — `window/bridge.md` — мост WebView2 между `window.py` и `ui/js/*.js`
- окно: экран — `window/screen.md` — заголовок, карточки и ошибки экрана по статусу службы
- окно: вкладки — `window/tabs.md` — настройки, журнал, «Сейчас подключено», листы конфига и перетаскивание `.conf`
- запуск: трей — `launch/tray.md` — один трей на сеанс, флаги окна, его показ и значок трея
- запуск: установщик — `launch/installer.md` — задача трея и `--background`, остановка, переезд с DualVPN, служба, права и задачи установщика
- запуск: обновление — `launch/update.md` — манифест трея, тихое обновление, WebView2, коды выхода и графика сборки
- туннели: формат — `tunnels/format.md` — формат `conf\tunnels.json`, переезд из `site.env` и правка через канал
- туннели: сборка — `tunnels/build.md` — сборка конфигов sing-box, теги, rule-set, проверка `add-config` и форма доменных записей
- туннели: на ходу — `tunnels/live.md` — собранные конфиги, профиль, боковые процессы и перезапуск на лету
